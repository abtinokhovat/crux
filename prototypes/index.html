A2

Your flow: question → your Claude → team review → you finalize → agents use it

chosen direction · builds on A
The agent is personal, not a team member. You capture a question (even mid-meeting, with teammates adding notes through a link). Your own Claude Code enriches the markdown locally: options, scenarios, links to other ADRs. The app only visualizes it. You shape it, share it as a PR, answer reviews, and finalize. Later, every agent reads the decisions — what was chosen, what was rejected and why, and when to reopen — before it changes code.

A

Decision as a pull request

Idea
Every ADR is a branch and a PR. A timeline of reviews, suggested changes to arguments, agent check comments, and a “Finalize” box that merges.
Best for
  • Engineering teams already living in GitHub
  • A full audit trail in git
Trade-off
  • Long threads; the structure is in the sidebar, not the body
  • Non-engineers find PRs heavy

B

Decision canvas

Idea
A board: one column per option, pro/con cards with reasons and +1s, a live weighting matrix, picks and a record step. The agent sits in a side panel.
Best for
  • Live workshops and design reviews
  • Seeing the whole trade-off at once
Trade-off
  • Needs people to come to the board
  • Dense on small screens
Open prototype B →
C

Asks inbox + decision room

Idea
Contributors never read the thread: they get focused asks with a TL;DR and answer choices. The decider gets a room with readiness, who-thinks-what, consensus and an agent brief. The agent has its own approval queue.
Best for
  • Busy, async teams
  • Getting input from people outside the core group
Trade-off
  • The full picture lives with the decider
  • Ask quality depends on the agent’s TL;DR

RECOMMENDATION

Combine them; don’t pick one. Use C’s asks to collect input (lowest effort, best response rate). Use B’s canvas as the decision page the asks link to. Use A’s PR as the storage and audit layer: arguments and the final ADR are commits on adr/NNNN-*, so the repo stays the source of truth. Agents act only through attributed, reversible suggestions.
